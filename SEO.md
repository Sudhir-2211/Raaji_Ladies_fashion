# SEO.md — Raaji Ladies Fashion

## 1. SEO Objective

The website should establish a strong local search presence for Raaji Ladies Fashion in Korattur and Chennai.

Primary search intent includes customers looking for:

- Ladies tailoring
- Ladies tailor
- Tailoring shop
- Custom tailoring
- Blouse stitching
- Salwar/Kurti tailoring
- Ladies fashion tailoring
- Tailor near Korattur
- Tailor in Chennai

The website should aim for strong organic visibility through accurate local information, useful content, technical quality, performance, and a consistent business identity.

Search rankings are not guaranteed.

---

# 6. Local SEO

Implement:

- LocalBusiness structured data where appropriate
- Accurate NAP information
- Location pages/content where genuinely useful
- Embedded/linked map functionality
- Directions CTA
- Contact CTA
- Relevant local internal links

Do not create multiple thin pages merely to target slightly different locations.

---

# 7. Structured Data

Use schema only when accurate.

Potential schema types:

- `LocalBusiness`
- Appropriate tailoring/business subtype if supported and accurate
- `BreadcrumbList`
- `FAQPage` where the visible FAQ content genuinely qualifies

Business schema should include verified information only.

Do not fabricate:

- Ratings
- Reviews
- Aggregate scores
- Awards
- Number of customers
- Years in business

---

# 8. Headings

Use one clear primary heading per page.

Recommended hierarchy:

```text
H1
  H2
    H3
```

Do not use headings merely to style text.

Use actual semantic headings.

---

# 9. Images

Every meaningful image should have descriptive alt text.

Examples:

Good:

`Custom blouse tailoring design by Raaji Ladies Fashion`

Better when specific:

`Embroidered bridal blouse tailoring design by Raaji Ladies Fashion`

Avoid:

`image1.jpg`

Decorative images may use empty alt text when appropriate.

---

# 12. Sitemap

Generate a sitemap containing public indexable pages.

At minimum:

- `/`
- `/gallery`
- `/services`
- `/price-guide`
- `/faq`
- `/about`

Do not include private, temporary, duplicate, or non-indexable routes.

# 13. Robots

Create an appropriate `robots.txt`.

Do not accidentally block:

- Main pages
- CSS
- Important JavaScript
- Images
- Search-engine crawlers from public content

---

# 14. Canonical URLs

Use canonical URLs where appropriate.

Avoid duplicate versions of the same page being indexed.
