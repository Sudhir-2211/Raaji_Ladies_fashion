# PROJECT.md — Raaji Ladies Fashion

## 1. Business Overview

**Business Name:** Raaji Ladies Fashion

**Business Type:** Ladies tailoring shop

Raaji Ladies Fashion is a tailoring shop where customers bring their own materials for stitching and tailoring services. The business focuses on quality tailoring, fitting, finishing, and ladies' fashion-related stitching requirements.

The website must clearly communicate that Raaji Ladies Fashion is a **tailoring shop, not a boutique**.

---

## 2. Website Purpose

The website should provide a professional online presence for Raaji Ladies Fashion and help potential customers quickly understand:

- What makes the shop unique
- What tailoring services are offered
- Approximate pricing
- Examples of completed designs and tailoring work
- Why customers should choose the shop
- How to contact the shop
- Where the shop is located
- How to visit the shop

The website should build trust and make it easy for potential customers to decide whether the shop's services are suitable for them.

---

## 3. Target Customers

The primary target audience is:

- Women looking for tailoring services
- Customers in Korattur
- Customers across Chennai
- Customers from nearby areas looking for ladies tailoring services

The website should be designed with a refined, elegant, feminine, and professional visual direction while remaining practical and easy to use.

---

## 4. Main Website Goals

The website should:

1. Establish a professional and trustworthy online presence.
2. Clearly explain the shop's tailoring services.
3. Display approximate pricing where appropriate.
4. Showcase completed tailoring work and designs.
5. Make contacting the shop easy.
6. Help customers find the shop and get directions.
7. Establish a strong local online presence in Chennai and Korattur.
8. Provide a smooth and premium browsing experience.
9. Make the website easy to maintain and update as the shop's designs and trends change.

---

## 5. Local SEO Goal

The website should be strongly optimized for relevant local searches and aim for high visibility for searches such as:

- Best tailor in Chennai
- Best tailor in Korattur
- Ladies tailor in Chennai
- Ladies tailor in Korattur
- Ladies tailoring services near Korattur
- Tailoring shop in Korattur
- Ladies tailoring shop in Chennai
- Tailor near Korattur

Search visibility should be improved through proper local SEO, useful content, technical SEO, page structure, metadata, structured data where appropriate, performance, mobile usability, and accurate business information.

Search rankings cannot be guaranteed and should not be represented as guaranteed.

---

## 6. User Experience

The website should feel:

- Premium
- Elegant
- Modern
- Rich
- Smooth
- Professional
- Visually appealing
- Easy to navigate

The experience should include:

- Seamless page transitions where appropriate
- Smooth scrolling
- Subtle animations
- Refined micro-interactions
- Clear visual hierarchy
- Consistent typography
- Consistent spacing
- High-quality imagery
- Responsive layouts
- Strong mobile experience
- Clear calls to action

Animations and visual effects must remain subtle and should never make the website feel slow, distracting, or difficult to use.

---

## 7. Performance Requirements

The website should be:

- Fast to load
- Responsive to user interaction
- Mobile-friendly
- Lightweight where possible
- Compatible with modern browsers
- Optimized for good Core Web Vitals
- Accessible to users with different devices and abilities

Images, animations, fonts, scripts, and other assets should be optimized so the visual quality does not unnecessarily reduce performance.

---

## 8. Content Strategy

The website content should be based on the actual business and should communicate:

- The shop's identity
- What makes the shop different
- Tailoring expertise
- Available services
- Approximate pricing
- Completed designs
- Customer benefits
- Location
- Contact information
- Relevant business details

Content should be clear, natural, trustworthy, and customer-focused.

Avoid generic claims that cannot be supported by the actual business.

---

## 9. Image and Design Updates

The website will regularly receive new images showing current designs, trends, and completed work.

The developer will manually:

- Add new images
- Remove outdated images
- Organize images by suitable categories
- Keep the gallery visually current

The initial website should therefore have a simple and organized image-management structure that makes these updates easy.

A customer-facing administration dashboard is not required at this stage.

---

## 10. Technical Direction

The website should use a modern, maintainable web architecture.

Preferred technologies:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Reusable components
- Git
- GitHub
- Vercel

The project should be structured cleanly so that individual pages, sections, components, images, and content can be updated without unnecessarily affecting unrelated parts of the website.

A backend and database should **not** be added unless a future requirement introduces functionality that genuinely requires server-side processing or persistent data.

---

## 11. Future Backend Consideration

The initial website does not require a backend simply for:

- Service information
- Pricing information
- Design galleries
- Contact details
- Phone links
- WhatsApp links
- Google Maps/location information
- Static business content
- SEO
- Analytics

A backend/database may be introduced later if requirements such as the following are added:

- Customer accounts
- Online appointment booking
- Customer measurement storage
- Order tracking
- Admin dashboard
- Online orders
- Payment processing
- Inventory management
- Persistent customer data
- Other server-side business functionality

If a backend becomes necessary, Python/FastAPI with MySQL is a preferred backend direction unless project requirements justify another architecture.

---

## 12. Development Standards

The website should be treated as a production website rather than a prototype.

Development should prioritize:

- Clean code
- Reusable components
- Maintainable folder structure
- Responsive design
- Accessibility
- Performance
- SEO
- Security
- Cross-browser compatibility
- Clear documentation
- Proper Git version control
- Thorough browser testing

All implemented features should be reviewed and tested before being considered complete.

---

## 13. Overall Vision

Raaji Ladies Fashion should have a polished, premium, smooth, and trustworthy online presence that:

- Clearly communicates the business
- Highlights the shop's tailoring services
- Shows approximate pricing
- Showcases current designs and completed work
- Makes contacting and visiting the shop simple
- Provides an excellent mobile experience
- Supports strong local search visibility
- Is easy to maintain and expand in the future

The final result should feel like a professional, established tailoring brand rather than a basic informational website.
